# Google Ads Extractor for AI

Chrome Extension (Manifest V3) giúp trích xuất nhanh dữ liệu từ trang quản trị **Google Ads** (`ads.google.com`) sang định dạng **Markdown** hoặc **JSON** để gửi cho AI phân tích.

## Cách tải và cài đặt

1. Tải mã nguồn về máy:
   - Bấm nút **Code (màu xanh) -> Download ZIP** trên GitHub, sau đó giải nén ra một thư mục.
2. Mở trình duyệt Chrome, truy cập: `chrome://extensions/`
3. Bật **Developer mode** (Chế độ dành cho nhà phát triển) ở góc trên bên phải.
4. Bấm **Load unpacked** (Tải tiện ích đã giải nén) và chọn thư mục vừa giải nén.

## Cách sử dụng

1. Mở trang **Google Ads** (`ads.google.com`) -> Vào phần **Overview**, **Campaigns**, **Ad groups**, hoặc **Search keywords**.
2. Bấm vào icon **Google Ads Extractor** trên thanh công cụ Chrome.
3. Chọn **📋 Copy Markdown** hoặc **📋 Copy JSON** rồi dán thẳng vào khung chat AI.
